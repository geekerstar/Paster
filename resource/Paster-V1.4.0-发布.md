# 剪贴板历史+12 套外观+截图录屏OCR翻译，Paster v1.4.0 来了

复制了一段代码、一张截图、一个链接，回头要用时翻了半天找不到——这大概是每个 Windows 用户都经历过的瞬间。

**Paster** 就是来解决这件事的。它常驻后台，自动记录你复制的所有内容，还集成了**截图、录屏、OCR 文字识别、离线翻译**。全部本地运行，**免费、隐私安全**。

🎨 **12 套外观** — 卡片 / 看板 / 时间线……随心切换

## 三、重要更新

### 🧰 工具栏自定义

12 套外观共用的顶部工具栏，现在完全由你定义——想留哪些按钮、排什么顺序，自己说了算。

自带「模拟工具栏」，所见即所得：候选区拖入即启用，工具栏内拖拽即可排序，蓝色插入线会提示落点位置。老版本已保存的配置自动兼容，无需手动重置。

### 🎨 12 套外观体系

在原来的「卡片模式 / 快捷插入」之外，一口气新增 10 套历史查看外观——便签墙、来源聚类、日历热力、瀑布流、图库网格、焦点轮播、主从聚焦、分类看板、时间轴流、智能标签。

每套外观支持独立参数，快捷键均可自定义。外观还在持续迭代美化中，欢迎反馈意见。

### 📷 截图

智能防遮挡、双屏精准采集，标注工具（矩形 / 箭头 / 马赛克 / 文字）齐全。ESC 一键取消选区，双屏下工具栏位置已修正，多屏用户放心用。

### 🎬 录屏

区域录屏，录制过程中可拖拽调整录制范围，不用重来。未安装 FFmpeg 时给出友好提示，不会卡死。

### 🔍 OCR 文字识别

框选区域即识别，结果可复制、可翻译。关闭识别窗口时自动退出截图模式，不会残留选区和遮罩。

### 🌐 离线翻译

离线翻译引擎稳定性增强，卡片、OCR 结果、阅读模式中均可右键即译，全程本地处理，不上传任何数据。

### ✅ 效率提升

- 卡片模式支持**全选** + 快捷键 **Ctrl+A**，批量操作一步到位。
- 托盘**左键单击**唤起的窗口可自定义，12 套外观任选。
- **收藏与置顶拆分**，可单独收藏，不影响置顶状态。
- 新增**数据清理**对话框，历史 / 收藏 / 便签 / 缓存可分项清理。
- **桌面贴图**增强：不透明度滑块调节，一键隐藏 / 显示。
- 复制时自动记录**来源应用**，可按来源聚类查看。
- 设置面板重组 + 性能优化，大历史量下热键唤起更流畅。
